# النظام الخارق للمعارف

منصة تربط الشركات والمقاولين والورش والمصانع والمهنيين والموردين والعملاء.

## ما تم بناؤه
- واجهة عربية RTL متجاوبة مع الهاتف.
- أقسام تعريفية لأنواع الحسابات.
- نموذج تسجيل نشاط/مستخدم.
- نموذج إضافة طلب تنفيذ أو توريد.
- لوحة متابعة محلية بعدّاد الحسابات والطلبات.
- تصدير البيانات التجريبية بصيغة JSON.

## تشغيل النسخة التجريبية
افتح `index.html` مباشرة أو فعّل GitHub Pages من إعدادات المستودع: Settings → Pages → Deploy from a branch → main → /(root).

## حدود النسخة الحالية
هذه واجهة MVP تجريبية. البيانات تُحفظ في متصفح الجهاز باستخدام localStorage فقط؛ لا يوجد حتى الآن خادم خلفي أو قاعدة بيانات مشتركة أو تسجيل دخول حقيقي أو صلاحيات مستخدمين أو ربط WhatsApp Business API. لا تُدخل بيانات عملاء حقيقية أو حساسة في هذه النسخة.

## المراحل التالية
1. خادم خلفي وقاعدة بيانات مشتركة.
2. تسجيل دخول والتحقق من رقم الهاتف.
3. صلاحيات وعزل بيانات كل شركة/ورشة/مهني.
4. نظام طلبات وعروض أسعار وموافقات واتفاقات ومراحل تنفيذ.
5. مطابقة الطلبات مع مقدمي الخدمة حسب التخصص والموقع والتوفر.
6. ربط WhatsApp Business Cloud API بعد إعداد حساب Meta ورقم مؤهل.
7. لوحة المدير الرئيسي وتقارير وتنبيهات ومراجعة الالتزامات المالية.

**قاعدة تشغيل:** لا يتم اعتماد التزام مالي أو عرض سعر نهائي أو اتفاق ملزم تلقائيًا؛ يتطلب موافقة المدير/صاحب الصلاحية.

## تجهيز قاعدة البيانات
تمت إضافة مخطط أولي لقاعدة بيانات PostgreSQL متوافق مع Supabase في:
`supabase/schema.sql`

يشمل:
- ملفات المستخدمين والأنشطة التجارية.
- عضويات وصلاحيات فرق العمل.
- طلبات التنفيذ والتوريد.
- عروض الأسعار ومتابعة النشاط.
- سياسات حماية البيانات (Row Level Security).

**لم يتم تشغيل المخطط على قاعدة بيانات فعلية بعد.** يلزم إنشاء مشروع Supabase ثم مراجعة المخطط وتشغيله من SQL Editor. لا تضع مفاتيح سرية أو أرقام وصول واتساب داخل ملفات الواجهة أو GitHub.


## نظام الاشتراكات
تمت إضافة أساس نظام الاشتراكات في:
- `supabase/subscriptions.sql` — الخطط، الاشتراكات، سجل المدفوعات، تجربة 14 يومًا، فترة السماح، ودوال صلاحيات الوصول ولوحة المدير.
- `docs/subscriptions.md` — السياسة المعتمدة، الأدوار، دورة الدفع، وتصميم لوحة الإدارة وخطوات الإطلاق.

شغّل `supabase/subscriptions.sql` بعد `supabase/schema.sql` من Supabase SQL Editor. **إضافة الملف إلى GitHub لا تشغّله تلقائيًا على قاعدة البيانات.** لا يوجد ربط دفع حقيقي أو واجهة اشتراكات مكتملة حتى الآن؛ يلزم ربط مزود دفع وخادم موثوق للتحقق من إشعارات الدفع قبل تفعيل الاشتراكات.
