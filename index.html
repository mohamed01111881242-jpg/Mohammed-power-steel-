إعدادات المنصة

حالة الاتصال

قاعدة البيانات السحابية غير مفعلة داخل الواجهة بعد

المشروع يحتوي على مخطط قاعدة بيانات Supabase داخل مجلد supabase، لكن هذه النسخة لا ترسل بيانات إلى السحابة. يلزم إعداد عنوان المشروع ومفتاح anon العام بعد التأكد من تشغيل الجداول وسياسات الحماية.

قنوات التواصل

واتساب هو قناة التواصل الأساسية المخطط لها. لم يتم توصيل WhatsApp Business Cloud API أو تشغيل رسائل آلية في هذه النسخة.

حماية البيانات

لا تدخل بيانات عملاء حقيقية أو حساسة في النسخة التجريبية؛ بياناتها محفوظة محليًا في متصفح هذا الجهاز فقط.

تنبيه: هذه نسخة MVP واجهة تشغيل تجريبية. التسجيل والطلبات والعروض تُحفظ محليًا في هذا المتصفح فقط، وليست قاعدة بيانات مشتركة بعد. لا توجد حتى الآن مصادقة حقيقية أو ربط واتساب أو إرسال إشعارات.
